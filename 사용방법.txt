MKR SYNC HTML 데스크톱 앱 사용방법
===================================

1. 필수 환경
-----------
- Windows 10/11
- Microsoft Edge WebView2 Runtime
- Microsoft Excel 데스크톱
- Classic Outlook 데스크톱
- PDF 보조 판독이 필요한 경우 Microsoft Word 데스크톱

새 Outlook, Microsoft Graph, OCR은 지원하지 않습니다.

2. 실행
------
1) Classic Outlook을 엽니다.
2) 작업할 Excel 파일은 닫아 둡니다.
3) MKR_SYNC.exe를 더블클릭합니다.

CMD나 외부 브라우저는 열리지 않습니다. HTML 화면이 MKR SYNC 창 안에 표시됩니다.

3. Excel과 MKR 시트
------------------
1) 대상 Excel 파일을 선택합니다.
2) MKR 설명문을 여러 줄로 붙여넣습니다.
3) 화면에 추출된 MKR 번호를 확인합니다.
4) '시트 생성 및 검증'을 누릅니다.

예:
MKR56/26・・・・・タイ産・アンソン向け・普通品
MKR56/26-1・・・タイ産・アンソン向け・専用品

MKR-20260910TG-A(T) 같은 P/O 번호는 제외됩니다.
Excel 시트명은 MKR56_26, MKR56_26-1처럼 '/'가 '_'로 변환됩니다.

외부 템플릿 우선순위:
1) MKR_SYNC.exe와 같은 폴더의 MKR_TEMPLATE.xlsx
2) settings.json에 저장된 사용자 지정 경로
3) 사용자가 선택한 Excel 파일

템플릿에는 MKR_TEMPLATE 시트가 있어야 합니다. 템플릿 파일은 읽기 전용으로 사용하며 수정하지 않습니다.
모든 대상 시트가 이미 정상이면 템플릿 파일이 없어도 다음 단계로 이동할 수 있습니다.

시트 생성 전 원본은 Backup 폴더에 저장됩니다. pending 파일을 모두 검증한 경우에만 원본을 교체합니다.

4. Outlook 분석 및 Excel 적용
----------------------------
1) 발신인 이메일을 한 줄에 하나씩 입력합니다.
2) 시작일, 최대 검색 건수(1~500), Outlook 폴더를 선택합니다.
3) 'Outlook 데이터 미리보기'를 누릅니다.

프로그램은 제목에서 MKR을 우선 찾고 필요하면 현재 메일 본문을 확인합니다.
주문 Excel, Sales Note PDF, 백오더 표와 후속 ETA/ETD 메일을 분석합니다.

결과 화면에서 MKR 행을 선택하면 품목별 R·S·P·K·L과 적용 규칙을 볼 수 있습니다.
Reports 폴더에는 MKR_PREVIEW_날짜시간.csv가 생성됩니다.
첨부파일은 MKR_Attachments/Run_... 폴더에 저장됩니다.

4) 오류가 없는 미리보기 결과를 확인합니다.
5) 'Excel에 적용'을 누르고 확인 창에서 적용을 승인합니다.

적용 범위:
- A10:E509: 신규 주문 품번, 품명, Order/Shipped/Shortage QTY
- H10:M509: 이 MKR에 포함된 백오더 번호, 품번, 품명, 수량
- D3: MKR 번호
- K4:K7: Order Date, Ship Date, ETA, ETD

Excel 적용 전 원본은 Backup 폴더에 저장됩니다. 프로그램은 pending 파일에 먼저 기록하고 값·헤더·병합 구조를 검증한 뒤에만 원본을 교체합니다.
미리보기 이후 Excel 파일이 변경되었거나 열려 있으면 적용하지 않고 다시 분석하도록 안내합니다.
적용 완료 보고서는 Reports/MKR_APPLIED_날짜시간.csv로 저장됩니다.

5. 수량 판정 기호
----------------
R = 최초 원본 주문수량
S = 최초 일반 Sales Note 선적수량
P = 최초 일반 Sales Note 주문수량
K = 백오더 Order QTY 합계
L = 이번 MKR에 포함된 백오더 Shipped QTY 합계

관계가 맞지 않거나 계산 결과가 음수이면 해당 MKR을 오류로 표시합니다. 다른 MKR은 가능한 범위에서 계속 분석합니다.

6. 결과 폴더
-----------
- Logs: 실행 과정과 오류
- Reports: CSV 분석 보고서
- Backup: 시트 생성 및 데이터 적용 전 대상 Excel
- MKR_Attachments: 실행별 Outlook 첨부파일
- settings.json: 사용자가 선택한 템플릿 경로

오류가 발생하면 Logs에서 가장 최근 MKR_SYNC_날짜시간.log를 확인하십시오.

7. 개발 및 재빌드
----------------
일반 사용자는 이 단계가 필요하지 않습니다.

- BUILD_MKR_EXE.cmd: Python 3.14 64비트로 EXE 재빌드
- 결과 위치: 현재 프로젝트 폴더의 MKR_SYNC.exe
- requirements.txt: pywin32, pywebview, pypdf, PyInstaller
- 기존 Tkinter 화면: python -m mkr_sync tk-gui
